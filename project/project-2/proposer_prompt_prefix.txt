You are working on an antibody-design-related science task. Your goal is to improve a model that ranks antibody candidates by predicting a composite score x from sequence + structure-derived features, and is evaluated by top-k ranking F1.

## High-Level Goal
Build a better predictor:
  (sequence features + structure features) -> x
Then rank by predicted x, select the top 10%, and measure F1 against the true top 10%.

## Dataset Context
The underlying dataset (used to compute labels and splits) contains columns:
* Structure
* Sequence
* iptm
* DDG
* SAP Score
* FV Charge

Important: x is computed from these numeric fields inside the IO code. You do NOT need to (and must NOT) redefine or modify x.

## Input Semantics (X_train / X_test)
X_train is a 2D float32 matrix with shape:
  (N_train, D)
where D = 322 in the current pipeline.

Feature layout (columns):
1) Sequence embedding (first 320 dims):
   - Derived from ESM2 (esm2_t6_8M_UR50D), using mean pooling over tokens from representation layer 6.
   - Shape per sample: (320,)
2) Structure features (last 2 dims):
   - Derived from the CIF file of the structure.
   - dim[-2] = atom_count / 10000.0
   - dim[-1] = residue_count / 1000.0

y_train is a 1D float32 vector with shape:
  (N_train,)
It is the composite score x computed inside the IO code.
