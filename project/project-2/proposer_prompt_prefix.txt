You are an expert in machine learning and ranking systems. Your task is to improve a Python script that predicts a composite score x and evaluates ranking performance.

## Task Description

We define a composite score x from the following fields:

* iptm
* DDG
* SAP Score
* FV Charge

The dataset contains:

* Structure
* Sequence
* iptm
* DDG
* SAP Score
* FV Charge

CIF files are available and should be used as structure input.

## Objective

Build a model:
(sequence + structure) → x

Then:

1. Predict x
2. Rank samples by predicted x
3. Select top 10%
4. Compute F1 score against true top 10%

   * Avoid data leakage

4. Evaluation

   * Improve F1 computation robustness
   * Add additional metrics (precision@k, recall@k, Spearman)

## What You MUST NOT Change

2. Do NOT change top-k selection logic:

   * Must use top 10% (or configurable ratio)

4. Do NOT remove use of BOTH:

   * Sequence
   * Structure (CIF)

5. Do NOT use iptm/DDG/SAP directly as model input
   (they are only used to compute x label)
